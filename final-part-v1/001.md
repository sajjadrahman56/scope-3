# 13. There is one thing I want you to be careful about

Your synthetic data generation currently uses **PCF itself as a CTGAN-generated variable**.

That's fine for synthetic-data generation.

But for your main prediction experiment:

```text
Target = PCF
```

you must make absolutely sure that the input features do **not contain PCF or a direct mathematical transformation of PCF**.

For example:

```text
PCF
Carbon Intensity = PCF / Weight
```

If you're predicting PCF and you give the model Carbon Intensity:

```text
Carbon Intensity = PCF / Weight
```

then you have **target leakage**.

This would make the model look artificially excellent.

So for the PCF prediction experiment:

### Target

```text
Product's carbon footprint (PCF, kg CO2e)
```

### Potential predictors

```text
Country
Company
Product
Product Detail
Industry
Sector
Product Weight
Year
Stage-level CO2e
...
```

But **not Carbon Intensity**, because it is mathematically derived from PCF.

This is one of the most important things we need to check before training your final models.
